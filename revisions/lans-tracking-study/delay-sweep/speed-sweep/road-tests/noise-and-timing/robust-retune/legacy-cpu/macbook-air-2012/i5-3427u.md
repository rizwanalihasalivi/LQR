# MacBook Air Mid 2012 timing and Windows comparison

The submitted physical MacBookAir5,2 used an Intel Core i5-3427U and macOS Catalina 10.15.7. The comparison run used a Core i5-1235U and Windows x64. Both bundles contain the same timing tape. Each controller processed 18,836 shared states over three repeats for 56,508 total decisions. Maximum reference steering differences match for all four controllers.

| Mac rank | Controller | Mac median, μs | Windows median, μs | Mac P95, μs | Windows P95, μs |
| ---: | --- | ---: | ---: | ---: | ---: |
| 1 | LQR | 0.062 | 0 | 0.07 | 0.1 |
| 2 | LANS | 1.897 | 1.5 | 2.285 | 1.9 |
| 3 | MPC | 3.892 | 1.5 | 2022.69725 | 860.865 |
| 4 | PPO | 14.4 | 11.8 | 15.0449 | 13.5 |

On the Mac, LANS ranks second by both median and P95. Its median is 1.897 μs, compared with 3.892 μs for MPC and 14.4 μs for PPO. LQR ranks first. On Windows, LANS and MPC both report a 1.5 μs median. The Windows timer reported zero for the LQR median and 0.0301 μs for its mean.

The Windows run’s LANS median was 20.9% lower than the MacBook’s. The numbers reflect the complete systems, including different operating systems, toolchains and clocks. The Windows launcher pins one logical CPU and macOS schedules the process.
